# KeyChord Matrix Probe (US ANSI)

A single-page tool that works out the keyboard matrix (which key combinations the
hardware drops) of a US ANSI keyboard, for the KeyChord project.

Open the published page, follow the on-screen steps (hold a pair of keys, tap the
highlighted keys, then a few 4-6 key chords), then press **Copy Report** and paste the
result back into KeyChord.

It is a browser port of KeyChord's built-in Matrix Scan. Everything runs locally in the
page; nothing is uploaded. Progress is saved in the browser's local storage.
